# Assassin's Creed Valhalla — українською

Українська локалізація **Assassin's Creed Valhalla**: уся гра й усі доповнення.

| | |
|---|---|
| Версія перекладу | **v0.5.3** (23.11.2026), ранній доступ |
| Версія гри | Steam, збірка 26142239 |
| Платформа | Steam (Windows; Steam Deck / Linux через Proton) |

## Що перекладено
- **Окремі версії для Ейвор-жінки та Ейвор-чоловіка** — звертання, дієслова й прикметники узгоджені з обраною статтю героя.
- **Основна гра повністю:** меню й налаштування, завдання, описи, предмети, кодекс, підказки та всі 42 тисячі реплік діалогів.
- **Усі доповнення:** «Гнів друїдів», «Облога Парижа», «Світанок Раґнарьоку», «Забута сага», «Нова гра+» і вибір режиму, безкоштовні оновлення (річкові набіги, фестивалі, Асгард), набори спорядження.
- **Випробування майстерності.**
- Звуки й ремарки в субтитрах — українською; латинські, французькі та валлійські фрази — в оригіналі з перекладом у дужках.
- Єдиний словник імен і назв.

## Встановлення
**Через [LBK Launcher](https://lbklauncher.com/)** — знайдіть гру й натисніть «Встановити».

**Вручну:**
1. Закрийте гру.
2. Завантажте архів з [останнього релізу](../../releases/latest).
3. Розпакуйте весь вміст архіву в теку гри — туди, де лежить `DataPC.forge` (Steam → гра → Керувати → Переглянути локальні файли).
4. У налаштуваннях гри оберіть мову **English** (англійська).

## Видалення
Запустіть `INSTALL.bat /uninstall` у теці гри — або просто видаліть файли `DataPC_patch_02.forge`, `DataPC_*_dlc_patch_02.forge` і `DataPC_255_dlc_patch_01.forge`. Файли самої гри переклад не змінює.

## Як це працює
Переклад — це окремі файли-патчі поруч із файлами гри: гра підхоплює їх замість англійського тексту. Оновлення гри може вимагати нової версії перекладу — стежте за релізами.
